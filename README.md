# Proyecto Fullstack CodeW3B

Este repositorio contiene el desarrollo de una aplicación web moderna, enfocada en una arquitectura limpia y una interfaz de usuario adaptable (responsive).

## 🚀 Demo en Vivo
Prueba el proyecto en vivo aquí: [https://codew3b.netlify.app/#/](https://codew3b.netlify.app/#/)

## 🛠️ Tecnologías Utilizadas
* **Frontend:** Vue.js, JavaScript (ES6+)
* **Estilos:** HTML5 y CSS3 (Diseños avanzados con Flexbox y Grid)
* **Herramientas:** Git, GitHub, Netlify para el despliegue

## 📝 Resumen del Proyecto
Este proyecto demuestra mi capacidad para construir aplicaciones frontend escalables y fáciles de mantener. Las características clave incluyen:
* **Diseño Web Adaptable:** Totalmente optimizado para vistas de móviles, tablets y escritorio.
* **Arquitectura Basada en Componentes:** Construido con Vue.js para una gestión eficiente del estado y reutilización de la interfaz.
* **CSS Bootstrap:** Implementación de estilos.
